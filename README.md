# Sentiment_Analyzer

## Motivation
This project was developed as part of Atil Samancioglu's Deep Learning Course to practice and apply Sentiment Analysis models.

## Quick Start
To get a local copy up and running, follow these simple steps:

1. Clone the repository:
   ```bash
   git clone [https://github.com/alizeidil/Sentiment_Analyzer.git](https://github.com/alizeidil/Sentiment_Analyzer.git)

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt

## Usage 
To train the model or run predictions, execute the relevant script or Jupyter Notebook:
```bash
python sentiment_analyzer.py
```
